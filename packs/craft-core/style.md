# 写作工艺（强制）

## 禁止（正文出现即判劣质）
- **啰嗦**：同一意思反复换词；禁止段末总结刚发生的事
- **重复**：同句式/同信息复读；刚写过的动作对白不要换皮再写
- **电报文**：通篇碎片短句、无感官无反应
- **顶真文**：滥用顶真连环制造假气势（偶用可以，连用超两句违规）
- **标语体**：海报金句硬塞（「这一刀注定改写命运」类）
- **口号体**：鸡血空喊（「我们一定能赢」「邪不胜正」堆叠）
- **讲课腔/说明书腔**：作者跳出来讲设定
- **总结腔**：「他明白了」「从今往后」类升华
- **空洞形容词**：无比强大/极其恐怖/震撼人心
- **说教内心**：他知道/他感到自己必须…

## 必须做到
- **人物丰富**：欲望、忌讳、声口、身体习惯；配角有立场
- **画面感**：视听触嗅味落到具体物件与动作
- **张力**：阻碍、时限、信息差、代价
- **合理引经据典**：符合身份与时代，点到为止
- **合理修辞**：为场面服务，禁止排比口号化
- **信息增量**：每大段推进情节/关系/信息/情绪之一
- **视角纪律**：单场视角稳定
- **对白有功能**：冲突、信息、关系或潜台词
- **因果与代价**：爽点落地为场面
- **节奏呼吸**：长短句交错；章末钩子具体
