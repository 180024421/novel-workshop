# 大帅墨枢 · 麒麟 / Linux

1. 下载 `DashuaiMoshu-*-linux-*.AppImage`
2. `chmod +x DashuaiMoshu-*.AppImage`
3. 双击或终端运行

或安装 deb：

```bash
sudo dpkg -i DashuaiMoshu-*-linux-*.deb
```

打开大帅墨枢 → 设置 → 粘贴 API Key 即可写作，无需外置网关。

## 授权与升级

1. 打开 **设置 → 授权中心**，粘贴卡密并激活。
2. 授权服务地址取自设置中的「更新源地址」；默认根地址为 `https://1ph1hf8043323.vicp.fun`。
3. 当前版本先通过 `GET /api/crypto/public-key` 取得公钥，再以 v1 RSA-OAEP（SHA-256）+ AES-256-GCM 加密信封 `POST` 调用授权的激活、状态刷新和解绑接口。旧版明文授权客户端不兼容，须安装包含新协议的正式新版。

若激活或刷新失败，请确认系统时间正确，并检查代理、防火墙、DNS 与当前网络能否通过 HTTPS 访问上述根地址和 `/api/crypto/public-key`。不要把完整授权接口路径填入「更新源地址」，也不要改用明文请求。

覆盖升级不会主动迁移或删除书稿：默认书稿在「文档/大帅墨枢」，自选书稿在创建项目时选择的目录；授权 ticket、设备 machine-id 和授权缓存位于 Electron `userData/license/`。安装新版时请保留这些目录，避免先卸载清理数据；重要书稿建议先在应用内创建本地 zip 备份。临时断网且本地 ticket 未过期时，客户端可继续使用缓存授权。

本应用没有调用远程 `usage-history`；写作字数和费用历史仅保存在本机 `userData/usage.json`。
