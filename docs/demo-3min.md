# 3 分钟演示脚本

## A. 官方样例《夜市刀客》

1. 首页点「打开样例书」→ 进入正文第1章，扫一眼对白烟火气  
2. 侧栏「扩展包」→「一键补工艺红线」（样例已含工艺，可再确认）  
3. 「本书健康分」看四维：细纲 / 钩子 / 工艺 / 摘要  
4. 正文工具：扫描工艺病 → 一键润色 → **必出**改前/改后 Diff  
5. 「声口体检」→「一键改对白」回写有问题的章  

推荐路径：**工艺包 → 健康分 → 再写新章**。写章前可开「上下文预览」，勾选块会作为 `contextBlocks` 显式注入写章请求。

## B. 导入己书改稿

1. 首页「导入书稿」→ 选 TXT/MD → 预览里可改标题 / 合并 / 删章  
2. 创建项目后勾选：生成第1卷目录 + 补工艺红线 →「补结构并去第1章润色」  
3. 正文工具：扫描 → 工艺润色 → Diff 采纳  
4. 侧栏或卷章管理「+新建章 / +新建卷」继续写  
5. 改稿队列可「批量工艺润色」（逐章备份写回）  

导入与从零共用同一本书模型。结构可手搓，不依赖 AI 也能加卷加章。
